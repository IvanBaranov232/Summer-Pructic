# Как соединить MainMenu и pupa в один проект — полный гайд

Я распаковал и изучил твои файлы. Сразу два важных момента:

1. **Загрузился только `pupa.unitypackage`** (18 МБ). `MainMenu.unitypackage`
   до меня не дошёл — видимо, вторая загрузка сорвалась. Гайд ниже полный и
   рабочий в любом случае, но если хочешь, чтобы я проверил содержимое именно
   меню — перезалей `MainMenu.unitypackage`.

2. **`pupa` — это весь игровой проект**, а не кусочек. Внутри: все скрипты
   (Core, Towers, Enemies, Waves, Building, UI, Data), все префабы (EP_*, TP_*,
   снаряд), ассеты-данные врагов и башен, **твоя графика** (папки `враги/`,
   `башни/`, картинки `Уровень 1–5.png`) и **5 готовых сцен уровней**:
   `map 1.unity` … `map 5.unity`. Плюс почти пустые `Game.unity` и
   `SampleScene.unity`.

То есть `pupa` = вся игра кроме меню, а `MainMenu` = сцена меню. «Соединить» —
значит собрать их в одном проекте и связать так, чтобы из меню открывались
твои 5 уровней.

> **Важно — я нашёл, почему уровни не открываются из меню.** В коде проекта
> кнопки меню грузят сцену с именем **`Game`** (а она у тебя пустая), а реальные
> уровни лежат в сценах **`map 1` … `map 5`**. И ещё: во всех пяти сценах у
> объекта Managers стоит **Level Number = 1**, поэтому даже открыв любую из них,
> ты получишь волны 1-го уровня. Ниже — как это поправить. Это и есть главная
> часть «соединения».

<a name="часть-1"></a>
## Часть 1. Что такое .unitypackage и как импортировать

`.unitypackage` — это коробка с ассетами Unity (сцены, скрипты, префабы,
картинки) вместе с их связями. Её **нельзя просто распаковать в папку** —
её надо **импортировать внутрь открытого проекта Unity**, тогда Unity разложит
всё по местам и сохранит связи между объектами.

Импорт делается так (пригодится дальше):
- **Assets → Import Package → Custom Package…** → выбрать файл `.unitypackage`
  → откроется окно со списком ассетов и галочками → **All** → **Import**.

Или просто перетащить файл `.unitypackage` в окно **Project** открытого Unity.

<a name="часть-2"></a>
## Часть 2. Какой проект брать за основу

У тебя два пути. Выбери **один**.

**Путь А (проще, рекомендую): один из пакетов уже содержит почти весь проект.**
`pupa` — это и есть полный игровой проект. Значит:
1. Создай **новый пустой 2D-проект** (Unity Hub → New → 2D Core), назови
   например `TowerDefenseFinal`.
2. Импортируй в него **сначала `pupa`**, потом **`MainMenu`** (Часть 3).
3. Дальше по гайду.

**Путь Б: если у тебя уже есть рабочий проект, где ты делал уровни.**
Тогда новый создавать не нужно — `pupa` это, скорее всего, экспорт как раз из
него. Просто открой свой проект и импортируй в него **`MainMenu`** (одного
пакета достаточно, всё остальное уже на месте). Переходи к Части 4.

> Если не уверен — иди по Пути А с чистым проектом. Так точно не будет мусора
> от старых экспериментов.

<a name="часть-3"></a>
## Часть 3. Импорт обоих пакетов

(Путь А. Если идёшь по Пути Б — импортируй только MainMenu.)

1. Открой пустой 2D-проект.
2. **Assets → Import Package → Custom Package…** → выбери **`pupa.unitypackage`**
   → в окне нажми **All** → **Import**. Подожди — импортируется ~146 ассетов,
   включая TextMesh Pro. Если Unity предложит импортировать **TMP Essentials** —
   согласись (или сделай Window → TextMeshPro → Import TMP Essential Resources).
3. Дождись компиляции. Открой **Console** — красных ошибок быть не должно.
   - Если ругается на отсутствие **Input System** или **Universal RP** —
     в пакете есть ссылки на них. Поставь через **Window → Package Manager**:
     найди **Input System** и **Universal RP**, нажми Install. (Если твой
     проект 2D Core — URP уже стоит.)
4. Теперь импортируй **`MainMenu.unitypackage`** тем же способом
   (Import Package → Custom Package → All → Import).
5. После импорта в **Project → Assets/Scenes** у тебя должны появиться:
   `MainMenu.unity` (из второго пакета) и `map 1` … `map 5`, `Game`,
   `SampleScene` (из pupa).

> Если в окне импорта MainMenu часть строк помечена как **уже существующие**
> (с пометкой, что файл будет перезаписан) — это нормально и ожидаемо, см.
> Часть 4.

<a name="часть-4"></a>
## Часть 4. Если скрипты задвоились (конфликт)

Оба пакета могли содержать **одни и те же скрипты** (GameManager, HUD и т.д.).
Возможны два сценария:

**Сценарий 1 — скрипты совпали (один и тот же файл).** Если оба пакета
экспортированы из одного проекта, у скриптов **одинаковые GUID**, и при импорте
MainMenu они просто перезапишут такие же — дублей не будет. Ничего делать не
надо. Это самый частый случай.

**Сценарий 2 — в Console ошибки вида «The class ... is defined in multiple
places» или дубли папок `Scripts 1`, `Assets/Scripts/Core` появилась дважды.**
Значит пакеты из разных проектов и скрипты задвоились. Чини так:
1. В **Project** найди задвоенную папку (например `Scripts 1` или второй
   `GameManager.cs`).
2. Оставь **один** комплект скриптов (любой, они одинаковые по коду), **второй
   удали** (ПКМ → Delete).
3. Дождись пересборки, проверь Console.

> Как понять, что удалять: дубли обычно лежат рядом с пометкой ` 1` в имени
> или в лишней папке. Удаляй именно копию, а не оригинал из `Assets/Scripts/...`.

После этого шага красных ошибок в Console быть не должно.

<a name="часть-5"></a>
## Часть 5. Привязка номера уровня к каждой сцене

Сейчас во **всех** сценах `map 1`…`map 5` у объекта **Managers** стоит
`Level Number = 1`. Из-за этого любая карта запускает волны и баланс **первого**
уровня. Надо проставить правильный номер каждой сцене.

Для каждой из пяти сцен:
1. В **Project → Assets/Scenes** двойным кликом открой `map 1.unity`.
2. В **Hierarchy** выдели объект **Managers**.
3. В **Inspector** найди компонент **Game Manager** → поле **Level Number**.
4. Поставь номер, соответствующий карте:
   - `map 1` → **Level Number = 1**
   - `map 2` → **Level Number = 2**
   - `map 3` → **Level Number = 3**
   - `map 4` → **Level Number = 4**
   - `map 5` → **Level Number = 5**
5. **Сохрани сцену:** Ctrl+S (Cmd+S). Это обязательно — иначе номер не
   запишется.
6. Повтори для остальных четырёх сцен.

> Почему это важно: номер уровня управляет тем, какие враги и сколько волн
> придёт (через `LevelDatabase`), сколько денег на старте и насколько толстые
> враги. `map 3` с номером 3 даст босса в финале, `map 5` — двух боссов и т.д.

<a name="часть-6"></a>
## Часть 6. Чтобы меню грузило нужный уровень (правка кода)

Это ядро «соединения». Сейчас кнопки меню вызывают загрузку сцены с именем
**`Game`** (пустой). Нужно, чтобы кнопка уровня N открывала сцену **`map N`**.

Меняем **один файл**: `Assets/Scripts/Core/SaveSystem.cs`.

1. В **Project** найди `Assets/Scripts/Core/SaveSystem.cs`, открой двойным
   кликом (откроется в твоём редакторе кода).
2. Найди внутри класс `LevelLoader` и в нём метод `LoadLevel`. Сейчас он такой:

```csharp
public static void LoadLevel(int level)
{
    SelectedLevel = level;
    Time.timeScale = 1f;
    SceneManager.LoadScene(GameSceneName);   // грузит "Game"
}
```

3. Замени строку загрузки так, чтобы грузилась сцена `map N`:

```csharp
public static void LoadLevel(int level)
{
    SelectedLevel = level;
    Time.timeScale = 1f;
    SceneManager.LoadScene("map " + level);  // грузит "map 1", "map 2", ...
}
```

> **Важно про пробел и имя.** Твои сцены называются `map 1`, `map 2` — с
> маленькой буквы и **с пробелом** перед цифрой. Строка `"map " + level` даёт
> ровно `map 1`. Если переименуешь сцены (например в `Level1` без пробела) —
> поменяй и строку (`"Level" + level`). Имя в коде должно совпадать с именем
> файла сцены буква-в-букву.

4. Заодно проверь строку перезапуска уровня (кнопка «Заново» на экране конца
   игры). В том же файле метод:

```csharp
public static void ReloadCurrent()
{
    Time.timeScale = 1f;
    SceneManager.LoadScene(SceneManager.GetActiveScene().name);
}
```

Она грузит **текущую** сцену по её имени — это уже правильно работает с
`map N`, менять не надо.

5. И проверь имя сцены меню. В том же классе:

```csharp
public const string MenuSceneName = "MainMenu";
```

Если твоя сцена меню называется ровно **`MainMenu`** (как файл `MainMenu.unity`)
— всё ок. Если у тебя она называется иначе — впиши сюда её точное имя. Кнопки
«В меню» используют именно это имя.

6. Сохрани файл, вернись в Unity, дождись пересборки.

> Строку `GameSceneName = "Game"` можно оставить — она больше не используется
> для уровней, мешать не будет. Удалять не обязательно.

<a name="часть-7"></a>
## Часть 7. Build Settings — порядок сцен

Unity грузит по имени только те сцены, что добавлены в Build Settings. Добавим
меню и все карты.

1. **File → Build Settings** (в новых версиях — **File → Build Profiles**,
   суть та же).
2. Открой сцену **`MainMenu`** (двойной клик в Project) и в окне Build Settings
   нажми **Add Open Scenes**.
3. По очереди открывай `map 1`, `map 2`, `map 3`, `map 4`, `map 5` и каждый раз
   жми **Add Open Scenes**.
4. В списке **Scenes In Build** должно быть 6 сцен. **`MainMenu` должна быть
   первой** (индекс 0) — игра стартует с неё. Если не первая — перетащи наверх
   мышкой.
5. Порядок `map 1`…`map 5` после меню не важен (грузятся по имени, не по
   индексу), но для порядка пусть идут по возрастанию.
6. `Game` и `SampleScene` добавлять **не нужно** (они пустые/лишние). Если уже
   добавились — можно снять у них галочку слева в списке.

Должно получиться примерно так:
```
☑ MainMenu      0   <- первая!
☑ map 1         1
☑ map 2         2
☑ map 3         3
☑ map 4         4
☑ map 5         5
```

<a name="часть-8"></a>
## Часть 8. 5 уровней вместо 9 (если ещё не сделал)

В импортированном `pupa` скрипты пока на **9 уровней** (я проверил:
`LevelDatabase.cs` → `LevelCount = 9`, `LevelSelectUI.cs` → `TotalButtons = 10`).
Раз у тебя 5 карт и игра на 5 уровней — поправь два числа:

1. `Assets/Scripts/Data/LevelDatabase.cs`:
   ```csharp
   public const int LevelCount = 5;
   ```
   И массив `Titles` оставь из 5 названий (лишние можно убрать).

2. `Assets/Scripts/UI/LevelSelectUI.cs`:
   ```csharp
   private const int TotalButtons = 6;   // 5 уровней + «Will be soon»
   ```

3. В сцене `MainMenu`: объект сетки кнопок (`LevelGrid`) → компонент **Grid
   Layout Group** → **Constraint = Fixed Column Count**, **Count = 3** (ровные
   3×2 для шести кнопок).

> Если тебе наоборот нужно оставить 9 уровней — тогда не трогай эти числа, а
> просто сделай ещё 4 сцены `map 6`…`map 9` по образцу первых и добавь их в
> Build Settings. Но раз карт пять — логичнее `LevelCount = 5`.

> Про боссов: в коде боссы выходят по правилу `if (level % 3 == 0)`. При 5
> уровнях это даст босса только на 3-м. Хочешь босса и на финальном 5-м —
> в `LevelDatabase.cs` в конце метода построения волны замени строку с боссом
> на `if (level == 3 || level == 5)` и `level == 5 ? 2 : 1` (два босса на
> финале). Подробности — в файле LevelDatabase, там есть комментарии.

<a name="часть-9"></a>
## Часть 9. Проверка

1. Открой сцену **`MainMenu`**, нажми **Play**.
2. Чек-лист:
   - [ ] В меню видно кнопки уровней (5 + «Will be soon», если сделал Часть 8).
   - [ ] Уровень 1 доступен, остальные с замком (открываются по прохождению).
   - [ ] Клик по уровню 1 открывает сцену **`map 1`** (а не пустую Game).
   - [ ] На карте идёт игра: считаются деньги/жизни, кнопка запуска волны
         с отсчётом, башни ставятся и стреляют.
   - [ ] Прошёл уровень → «ПОБЕДА», в меню открылся уровень 2.
   - [ ] Кнопка уровня 2 открывает **`map 2`**, и волны там сложнее (потому что
         Level Number = 2). Если на всех картах одинаковая сложность — значит
         где-то остался Level Number = 1 (вернись в Часть 5) или не сохранил
         сцену.
   - [ ] Кнопка «В меню» с экрана победы/поражения возвращает в MainMenu.

Если всё это работает — пакеты соединены, меню и уровни связаны.

<a name="если-не-работает"></a>
## Если не работает

**Клик по уровню открывает пустую сцену (только камера и квадрат).**
Это грузится `Game` вместо `map N`. Проверь Часть 6: в `SaveSystem.cs` строка
должна быть `SceneManager.LoadScene("map " + level);`. И проверь, что сцены
`map 1`…`map 5` добавлены в **Build Settings** (Часть 7) — без этого Unity не
найдёт их по имени и кинет ошибку в Console «Scene 'map 1' couldn't be loaded».

**Ошибка в Console: «Scene 'map 1' couldn't be loaded … not been added to the
build settings».**
Добавь все карты в Build Settings (Часть 7).

**На всех уровнях одинаковая сложность / одинаковые волны.**
У какой-то сцены остался `Level Number = 1`, или ты не сохранил сцену после
изменения номера. Пройди Часть 5 заново, после каждой правки **Ctrl+S**.

**Console: «class GameManager is defined in multiple places» (или другой
скрипт).**
Скрипты задвоились при импорте. Удали лишнюю копию папки/файла (Часть 4),
оставь один комплект в `Assets/Scripts/...`.

**Меню вообще не загружается при старте / стартует не та сцена.**
В Build Settings **MainMenu** должна быть на позиции **0** (самой первой).
Перетащи её наверх.

**Кнопка «В меню» не работает / грузит не то.**
В `SaveSystem.cs` проверь `MenuSceneName = "MainMenu"` — имя должно совпадать
с именем файла сцены меню.

**После импорта розовые (magenta) объекты или «сломанные» материалы.**
Это несовпадение render pipeline (URP). Убедись, что стоит **Universal RP**
(Window → Package Manager → Install), и что в **Project Settings → Graphics**
назначен URP-ассет (он есть в импорте: `Assets/Settings/UniversalRP.asset`).

**Не загрузился MainMenu.unitypackage (или нет сцены MainMenu в проекте).**
Второй файл до меня не дошёл при загрузке. Если сцены меню нет и в твоём
проекте — перезалей `MainMenu.unitypackage`, я проверю, что внутри. В крайнем
случае меню можно собрать заново по моему основному гайду (раздел про
MainMenu): сетка кнопок + компонент `LevelSelectUI`.

## Короткий чек-лист «соединено»

- [ ] Оба пакета импортированы в один проект (Часть 3)
- [ ] Скрипты не задвоены, Console без ошибок (Часть 4)
- [ ] У `map 1`…`map 5` проставлен Level Number 1…5 и сцены сохранены (Часть 5)
- [ ] `SaveSystem.cs`: `LoadScene("map " + level)` (Часть 6)
- [ ] Build Settings: MainMenu первой + все 5 карт (Часть 7)
- [ ] (опц.) LevelCount = 5, TotalButtons = 6, сетка 3 колонки (Часть 8)
- [ ] Play из MainMenu: уровни открывают свои карты с нужной сложностью
